# Glossary (Cl(2,0) sprint)

- **Grade** — degree of a basis blade: scalar (0), vectors e1/e2 (1), bivector e12 (2).
- **Geometric product** — single product that encodes dot- and wedge-like behavior; non-commutative.
- **Multivector** — sum of grades; our type has 4 coefficients `[s, e1, e2, e12]`.
- **Rotor** — even element (scalar + bivector) used for rotations via sandwich `R x R̃`.
- **Clifford linear layer** — for each output channel, sum of geometric products of input multivectors with learnable multivector weights (not ordinary matrix multiply on flattened ℝⁿ).
